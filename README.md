# dronetrack

This library aims to allow for plug-and-play precision loitering and landing for any autonomous drone using the dronekit library. You can use a combination of a variety of streams (onboard camera, IP stream), detectors (object detection models, april tag detectors), and trackers in order to find an object to locate and either loiter near or land on a given target.
